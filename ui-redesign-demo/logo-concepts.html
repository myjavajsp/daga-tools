前七个只动标内部的颜色配比，站其余部分不受影响；后两个是在试整站强调色——--accent 是一个 token，按钮、选中态、悬停、蓝点会一起变，所以真要换得连首页一起看。图形色对底按 WCAG 非文字 3:1 卡（实测值，不是估的）：结构色降到 #656c75 对白底 5.31:1、对纸白 #f7f8f9 4.99:1，仍过得去；再浅一档到 #cdd2d8 只剩 1.52:1，2.6px 的线会直接看不见，所以下限就停在 #656c75。蓝点侧：#1c47d6 对白底 7.19:1、对纸白 6.76:1，够；但压深底时必须换 #7c96ef（对 #0e1116 6.72:1；#1c47d6 直接压在墨底上只有 2.63:1，过不了线）。

C

影 · 字标

现有方向精修我的推荐

把 demo 里那颗墨块升级成真正的资产：「影」不再是画在上面的白字，而是镂空——透出所在底色，所以放在纸上、白卡上、照片上都不会出现"贴了一块白"的廉价感；右下角咬出一条透明缝，蓝点悬在缺口里，任何底色都不糊。单色场景直接用整块镂空，不依赖第二个颜色。

C · 与现版 demo 同尺寸，直接可替换

一个必须说清楚的限制：中文字标的字形依赖字体。这里的「影」用的是系统字体（苹方／微软雅黑）实时渲染，作为概念稿成立；正式交付必须选一款可商用的中文字体，把字转曲成 path 再出 SVG，否则换一台机器、换一个浏览器笔画会抖。要走到那一步，我需要一个字体授权方向（思源黑体免授权，站体气质偏软；阿里巴巴普惠体免授权但字形偏圆；要更硬朗得买方正／汉仪的字库授权）。

抖音去水印

微标：16px 放不下「影」，换笔画

扫描线实测：同一条横线在 112px 下能数出 4 / 4 / 3 / 3 / 6 段「影」的笔画，压到 16px 只剩 2 / 2 / 2 / 2 / 3 段——镂空并成一块墨，认不出是字。所以正式交付里 16px（favicon、App 图标、视频水印）用微标，28px 以上才用「影」。微标二选一：片（承接"影片"，笔画少但仍是个字）或 纯块缺口（只留墨块＋蓝点，最小也最稳）。
