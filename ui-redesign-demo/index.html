怎么用

    复制播放页地址

    在视频网站点开某一集，复制浏览器地址栏里那一串，不要复制分享口令。

  2. 02

    粘贴并选线路

    放进上方解析框，先用默认线路；不同站点在不同线路上的兼容性差别很大。

  3. 03

    点解析播放

    画面出现在右侧播放器，默认尝试 1080P，清晰度由源站决定。

  4. 04

    不通就换一条

    一直转圈或黑屏时，依次切到线路 2、线路 3；刷新后重试通常能解决。
